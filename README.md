# Papon Wikipedia-style client preview

This build closely reproduces the current Wikipedia Vector 2022 desktop layout and a compact mobile layout, while using generic branding and a clear independent-preview notice. It is not an official Wikipedia page.

# Papon proposed article preview

A responsive client-review mock-up showing how the proposed Papon article and expanded song list could look after editorial approval.

## Important

- This is **not an official Wikipedia page**.
- The Wikimedia Foundation is not affiliated with or endorsing this preview.
- The official Wikipedia globe logo and wordmark are not used.
- The controversy section is intentionally omitted from the public preview as requested.
- The court order is retained only in the `editorial-review` folder as supporting material.

## Repository name

Recommended: `papon-wikipedia-preview`

## Publish with GitHub Pages

1. Create a public GitHub repository named `papon-wikipedia-preview`.
2. Upload every file and folder from this package so `index.html` is in the repository root.
3. Go to **Settings → Pages**.
4. Set **Source** to `Deploy from a branch`.
5. Choose branch `main` and folder `/ (root)`.
6. Save.

Expected URL:

`https://manjul0508.github.io/papon-wikipedia-preview/`
